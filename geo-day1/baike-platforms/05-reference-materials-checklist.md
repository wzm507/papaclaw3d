# 百科参考资料准备清单

## 必备材料

- [ ] 营业执照或公司主体信息截图
- [ ] 天眼查链接
- [ ] 企查查链接
- [ ] 官网首页链接
- [ ] 官网备案信息截图或链接
- [ ] 公司 logo 图片
- [ ] 公司简介 300 字以内
- [ ] 业务范围说明
- [ ] 公众号或其他公开平台文章链接

## 最好补充

- [ ] 百家号文章链接
- [ ] 搜狐号/网易号/腾讯内容开放平台文章链接
- [ ] 行业媒体报道链接
- [ ] 创始人公开采访或介绍链接
- [ ] 线下活动、合作、参会的公开报道链接

## 不建议作为主要参考资料

- 小红书笔记
- 朋友圈截图
- 微信聊天记录
- 未公开 PDF
- 只有自己官网的单一链接
- 明显软文或招商广告
- 含电话、微信、二维码的页面

## 每个平台提交前检查

- [ ] 词条名是否与公司主体一致
- [ ] 摘要是否中立
- [ ] 正文是否没有夸大词
- [ ] 是否没有联系方式
- [ ] 是否没有“保证成交/保证中标”
- [ ] 参考资料是否能公开访问
- [ ] 每个核心事实是否有来源能支撑
